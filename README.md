# DevDeck releases

Installers for **DevDeck**, a control panel for your computer: system and network monitor, AI agents and AI editors (usage, cost, changes), Git dashboard, apps, cleanup and automation, for Windows and macOS.

This repository only holds the installers and release notes. Installed copies of DevDeck check here for updates.

## Install

**[Download the latest version →](https://github.com/vikram-capsitech/devdeck-releases/releases/latest)**

| System | File | Updates |
|---|---|---|
| Windows 10 / 11 | `DevDeck-Setup-x.y.z.exe` (recommended) | Automatic: DevDeck downloads new versions and offers "Restart to update" |
| Windows, no install | `DevDeck-Portable-x.y.z.exe` | DevDeck tells you when a new version is out |
| macOS (Apple silicon / Intel) | `DevDeck-x.y.z-arm64.dmg` / `-x64.dmg` | DevDeck tells you when a new version is out |

**First start**
- Windows shows "Windows protected your PC" because the app isn't signed with a paid certificate: click **More info → Run anyway**.
- macOS: right-click DevDeck in Applications → **Open**, then **Open** again (once).

Run DevDeck as your normal user, not as administrator; it asks for admin rights only for the actions that need them.
